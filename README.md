# Cultura da Brasa

Landing page responsiva da Cultura da Brasa.

## Estrutura
1. Hero
2. Diferenciais
3. Galeria
4. Sobre
5. Manifesto / Eventos
6. Área de Atendimento
7. Rodapé (último elemento)

A responsividade foi adicionada sem alterar a composição aprovada do desktop. O layout se adapta a notebook, tablet e celular, incluindo menu mobile, galeria em colunas menores, tipografia fluida e botões adequados ao toque.

## Publicação
Pode ser publicado como site estático no GitHub + Vercel.
